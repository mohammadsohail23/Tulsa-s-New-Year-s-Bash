Tulsa’s New Year’s Eve Bash 🎉

A class project website built with HTML, CSS, and JavaScript to showcase Tulsa’s annual New Year’s Eve celebration. The site highlights event details, activities, and local attractions while featuring a live clock and countdown timer to midnight.

🚀 Features
	•	Real-time date and time display using JavaScript
	•	Countdown timer to New Year’s Eve
	•	Event schedule and details for Tulsa’s celebration
	•	Links to activities such as FrostiRun, Kid’s Korner, Winter Art Fair, and live music events
	•	Custom styling with CSS (reset + theme)

🛠️ Tech Stack
	•	HTML5 – Structure and content
	•	CSS3 – Layout, design, and responsive styling
	•	JavaScript – Live clock and countdown functionality

📂 Project Structure
	•	index.html → Main page structure
	•	tny_styles.css → Custom styles
	•	tny_reset.css → Reset CSS
	•	tny_script.js → JavaScript for clock & countdown
	•	segment14.* → Fonts
	•	tny_banner.png → Banner image

🎯 Purpose

This project was developed as Class Project 2 for my Web Development course. It demonstrates my ability to combine semantic HTML, CSS styling, and JavaScript interactivity to build a themed, engaging website.
